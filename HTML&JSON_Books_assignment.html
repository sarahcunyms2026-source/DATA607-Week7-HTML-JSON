Reading and Comparing Book Data in R

Author

Sarah Abdelrahman

Published

October 18, 2026

Objective

This assignment demonstrates how to manually represent the same book data in HTML and JSON, load both formats into R data frames, and test whether the results are identical.

Selected books

I selected three books on Data Science and Machine Learning. Both R for Data Science and An Introduction to Statistical Learning have multiple authors. I recorded six attributes for each book: title, authors, year, publisher, ISBN, and subject.

The HTML file represents the books as rows in a table. The JSON file represents them as an array of book objects. Each object has the same six fields.

Bibliographic sources:

  • R for Data Science, 2nd Edition — O’Reilly
  • An Introduction to Statistical Learning, 2nd Edition — Springer
  • Hands-On Machine Learning, 3rd Edition — O’Reilly

3. Read the HTML table into an R data frame

read_html() parses the HTML document, html_element() selects the table identified as books, and html_table() extracts the table cells. The year column is converted to integer so that its data type matches the JSON data.

html_doc <- read_html(html_source)
html_books <- html_doc |>
  html_element("#books") |>
  html_table(convert = FALSE) |>
  as.data.frame(stringsAsFactors = FALSE)

html_books$year <- as.integer(html_books$year)

kable(html_books, caption = "Books loaded from HTML")

4. Read the JSON file into a separate R data frame

fromJSON() reads the JSON array and creates tabular data because every book object uses the same field names.

json_books <- fromJSON(json_source)
json_books <- as.data.frame(json_books, stringsAsFactors = FALSE)

5. Compare both data frames

identical() checks whether both objects have the same structure and values, including column types, row order, and column order. ISBN values are stored as character strings so their digits are preserved.

comparison <- identical(html_books, json_books)
cat("Are the HTML and JSON data frames identical?", comparison, "\n")
Are the HTML and JSON data frames identical? TRUE 
# Fail clearly if the two data sources ever stop matching.
stopifnot(comparison)

Conclusion

The same three books were encoded by hand in two different file formats. HTML uses table elements (<table>, <tr>, and <td>), while JSON uses an array ([]) of objects ({}). R can import both formats using rvest and jsonlite. The final identical() check verifies that both sources produce equivalent R data frames, provided their values, order, and data types match. This exercise builds a foundation for future web scraping and API assignments.
